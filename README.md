# Advent of Code 2025 🎄

My solutions for [Advent of Code 2025](https://adventofcode.com/2025) written in Go.

## Running Solutions

From the project root:

```bash
go run . <day-number>
```

**Example:**

```bash
go run . 1  # Run Day 1 solution
```
